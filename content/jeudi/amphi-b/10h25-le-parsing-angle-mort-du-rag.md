## Le sujet annoncé

Comprendre pourquoi le parsing est une étape importante dans la qualité d’un système RAG et comment examiner le résultat de cette étape.

## Petit lexique pour comprendre l’introduction

- **RAG** : approche qui recherche des informations dans des documents pour alimenter la réponse d’un modèle de langage.
- **Parsing** : extraction et structuration du contenu d’un document pour le rendre exploitable.
- **Chunk** : fragment de document utilisé dans une chaîne de recherche documentaire.

Ces définitions servent de contexte pédagogique ; elles ne reconstituent pas la partie manquante.

## Ce qui est effectivement dit

- La qualité d’un RAG peut plafonner.
- Le parsing est une première étape souvent sous-estimée.
- Améliorer cette étape peut améliorer la qualité de la chaîne.
- Le conférencier annonce des outils pour explorer le parsing et en valider la qualité.

## Ce qu’on ne peut pas restituer

Les outils montrés, les démonstrations, les résultats et l’approche « chunkless » annoncée dans le titre ne sont pas décrits dans l’extrait disponible.

## Ce que permet de retenir l’extrait
