# La positive alt-itude ! Un outil d'inclusion pour votre accessibilité

**Angi · Vendredi 10 novembre · Amphi C**

## Donner accès à l’information des images

Angi commence par faire entendre ce qu’un lecteur d’écran peut restituer. Les titres et les éléments de la page doivent avoir une structure cohérente. L’alternative d’une image s’inscrit dans cette lecture : elle aide à transmettre l’information qui manque quand on ne voit pas l’image.

## Choisir ce qui mérite d’être décrit

L’exemple d’un chaton qui parle devant un public de chatons montre comment faire une description courte. L’action, les personnages et la situation suffisent à comprendre la scène. Détailler toutes les couleurs, les pattes ou le microphone peut brouiller le message si ces éléments n’apportent rien à ce que l’image veut dire. Angi revient ainsi à la question du contexte : quelle information la personne doit-elle retrouver à cet endroit de la page ?

## Adapter la description au type d’image

Une image contenant du texte demande de restituer le contenu utile. Les couleurs ou l’ordinateur visible dans l’illustration n’ont pas besoin d’occuper la description si l’objectif est simplement de communiquer le message écrit. Une œuvre, à l’inverse, peut avoir son apparence comme information principale. Le choix et le niveau de détail dépendent donc de ce que la personne est venue consulter. Une même image peut demander une autre alternative quand elle remplit une autre fonction.

## Ce que j’en garde

Avant d’écrire l’alternative, formuler en une phrase le rôle de l’image dans le contenu. Relire ensuite la description avec le texte qui l’entoure permet de vérifier si l’information est compréhensible et si certaines précisions font doublon.
