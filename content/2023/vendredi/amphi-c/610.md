# Kstreamplify: simplifiez vous la vie avec le développement de vos applications  Kafka Streams

**Sébastien Viale et Clément Vacher · Vendredi 10 novembre · Amphi C**

## Simplifier un traitement Kafka Streams

Sébastien Viale et Clément Vacher utilisent un exemple d’enrichissement de colis. Un flux fournit les colis et un référentiel permet d’y ajouter des informations. Ils montrent les étapes du traitement et le code nécessaire pour les assembler, avant de présenter Kstreamplify pour faciliter cette mise en place.

## Lire le pipeline de bout en bout

L’exemple commence par la lecture du topic d’entrée. Le traitement joint ensuite le stream à une donnée de référence en sélectionnant une clé du colis, puis construit un résultat enrichi. Les intervenants rendent explicite ce qui circule entre les opérations. Cela permet de comparer la logique métier de l’enrichissement avec le code qui décrit la topologie.

## Rendre visibles les erreurs et les sorties

Ils introduisent des branches distinctes pour les résultats valides et les erreurs. La branche nominale et la branche d’erreur deviennent des sorties identifiables. La démonstration reprend ensuite le code pour montrer comment la bibliothèque allège les opérations récurrentes et aide à structurer le traitement. Les noms des branches rendent le parcours plus facile à suivre pendant la construction.

## Ce que j’en garde

Pour évaluer ce type de bibliothèque, reprendre un flux que l’on connaît et comparer ce qu’il faut écrire pour la lecture, l’enrichissement et les erreurs. Vérifier que les entrées et sorties du traitement restent lisibles dans le résultat.
