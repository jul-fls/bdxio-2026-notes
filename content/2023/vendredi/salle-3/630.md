# Micro-frontends : Angular, React et Vue dans une même application, oui c'est possible !

**Sébastien Oddo · Vendredi 10 novembre · Salle 3 (H1+H2)**

## Pourquoi découper le front

Sébastien Oddo présente plusieurs manières de faire cohabiter Angular, React et Vue dans une même interface. L’objectif est de découper un produit de façon à ce que différentes parties puissent évoluer avec davantage d’autonomie. Le choix technique vient après le découpage : est-ce que les fonctionnalités ont des frontières métier lisibles et est-ce que ces frontières se retrouvent dans l’interface et le code existants ?

## Choisir comment assembler les applications

Le talk compare des mécanismes de composition, dont Module Federation et les Web Components. Module Federation peut charger des modules à l’exécution et mutualiser certaines dépendances. Sébastien évoque aussi Native Federation et Piral. Dans une composition avec une application hôte, il faut décider ce que l’hôte prend en charge et ce qui appartient à chaque micro front-end. La discussion avec le public revient sur l’isolation, la compatibilité navigateur et le poids du JavaScript quand plusieurs parties utilisent le même framework.

## Ce que le découpage oblige à expliciter

Les parties de l’interface doivent parfois retrouver les mêmes préférences ou le même état de navigation. Sébastien cite le stockage temporaire de paramètres derrière une API lorsqu’un simple paramètre partagé ne suffit pas. Le style pose un problème similaire : il faut synchroniser ce qui donne une apparence commune tout en limitant les effets d’un changement de CSS sur une autre application. Côté Angular, il évoque également la difficulté à partager une instance unique de service et les surprises liées à l’initialisation quand on n’exécute plus l’application dans ses conditions habituelles.

## Ce que j’en garde

Avant d’adopter une technique de composition, faire l’inventaire des choses qui traversent les frontières : état utilisateur, navigation, styles, bibliothèques et services. Cela donne une idée du coût réel du découpage.
