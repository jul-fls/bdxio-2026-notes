# Jetpack Compose - Une révolution pour vos interfaces Android

**Thomas Tartas · Vendredi 10 novembre · Salle 3 (H1+H2)**

## Décrire l’interface dans le code

Thomas Tartas présente Jetpack Compose à partir de son expérience de développeur Android. Il oppose le parcours habituel avec des layouts XML et du code de mise à jour à une interface déclarée en Kotlin. L’idée est de décrire l’apparence à partir de l’état courant : quand cet état change, Compose peut mettre à jour les parties concernées.

## Comparer sur un exemple

Il montre un écran où une liste s’allonge au fur et à mesure. Le but est de comparer la quantité de code nécessaire pour obtenir le même comportement. Dans l’exemple projeté, la version Compose est environ quatre fois plus courte selon son décompte. Le résultat varie selon l’écran et les composants. Ce qui se remarque surtout dans la comparaison est la proximité entre ce qui est affiché et l’état qui le commande.

## Le retour d’expérience

Thomas raconte qu’il était sceptique quand il a commencé. Il a pu refaire avec Compose un écran qu’il connaissait déjà en XML. Cette réécriture lui a permis de comparer les deux approches sur un problème dont il connaissait les pièges et de constater le gain de temps dans son cas. Plutôt que de se limiter au code d’une démonstration neuve, il compare les gestes nécessaires pour faire évoluer un écran réel.

## Ce que j’en garde

Reprendre un écran connu avec un changement d’état simple, comme une liste qui grandit, permet d’évaluer la lisibilité du code et l’effort nécessaire pour modifier l’interface.
